当前现象：iframe 区域空白，攻击失败。

受保护站点的响应头包含 Content-Security-Policy: frame-ancestors ... （可能还有 X-Frame-Options: DENY），浏览器在渲染前就拒绝了本来源的嵌套—— JS 根本没有机会运行，这是点击劫持最强的防线。

想复现“劫持成功”？到 控制台 关闭 CSP frame-ancestors 与 X-Frame-Options（保留 JS 防嵌套可顺便观察它的告警），刷新本页再点“领奖”。
