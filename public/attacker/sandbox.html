实验 2：HTML5 iframe sandbox 绕过 JS frame-busting——证明“只靠 JS 防嵌套”不可靠。

复现步骤

  1. 到 控制台 关闭 CSP frame-ancestors 与 X-Frame-Options，保存。
  2. 切换下面的 sandbox 组合，然后刷新本页。
  3. 观察 iframe 内：top.location 跳转被吞掉，页面顶部出现红色拦截横幅。
  4. 回控制台查看报告：JS 记录 顶层跳转被阻止，Worker 仍在取证。
  5. 重新开启 CSP/XFO 并刷新——即使保留 sandbox，浏览器也直接不渲染。

要点：sandbox 是攻击者可控的宿主属性，受害者页面无法拒绝；因此 JS 防嵌套只能告警/遮挡， 真正的“禁止加载”必须由浏览器层的 frame-ancestors 完成。
